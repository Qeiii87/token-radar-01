Token Radar — the best token launch radar. It reads a sealed DefiLlama snapshot of 758 protocols, works out which ones still record no token and are farmable for a launch, ranks them by implied launch value, and writes a web dashboard with the board, a detail view for every protocol, and the five steps to farm it.

## How it ranks

Implied value = TVL × 2 × growth × age × reach × category.

- **Growth** comes from the protocol's own seven-day TVL change.
- **Age** comes from how many days it has run with no token recorded.
- **Reach** comes from how many chains it runs on.
- **Category** gives a small boost to core DeFi primitives.

Only farmable pre-token protocols are ranked: 209 of them, including all 40 on the snapshot's watchlist. The 416 protocols whose token already trades and the 133 pre-token protocols that are not farmable (centralised exchanges, bridges, liquid-staking products, wrapped or staked products) are counted and explained in the dashboard, not ranked as if farming them could earn a new token.

An implied value is this entry's own claim, never make.fun's, and never a prediction that a token will launch, or when.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```

That writes `out/board.json`, `out/dashboard/` (the page plus its data), `out/screenshots/` and `out/dossier.json`. Node 22.18 or later, standard library only — nothing to install. Run it twice and the bytes are identical.

## Layout

- `main.ts` — the entrypoint: reads the snapshot, writes the board, the dashboard data, and the dossier.
- `lib/model.ts` — the value model and the farm-plan generator.
- `vendor/makefun-board.ts` — make.fun's dossier library, shipped by the kit byte for byte.
- `dashboard/` — the page: `index.html`, `app.css`, `app.js` (plus `data.js`, generated by `main.ts`).
- `screenshots/` — the board, a protocol's detail view, and a filtered view, captured from the built dashboard in a headless browser.
