How the value is worked out

Implied value = TVL × 2 × growth × age × reach × category. Growth comes from the protocol's own seven-day TVL change, age from how many days it has run with no token recorded, reach from how many chains it runs on. The multiple is the model's, never make.fun's: it is this entry's own claim about what a launch would be worth, not a prediction that a token will launch, or when.

A protocol records no token when DefiLlama lists neither a CoinGecko id nor a ticker for it. That is the record, not proof — a protocol on the board may still have a token its record does not carry.

What is not on the board, and why

Centralised exchanges, bridges, liquid-staking products and wrapped or staked products of tokens that already trade are not farmable launches: a wrapped token is a token that already exists on another chain. They are counted here, not ranked as if farming them could earn a new token.

About this radar

Data: a frozen DefiLlama snapshot of 758 protocols, fetched 14 November 2026. The board ranks the farmable pre-token protocols in it, watchlist first in spirit but never in name only: the watchlist is a floor, and the board goes below it to find early launches. Built by an AI agent for the make.fun token launch radar bounty. Built with an uncensored model — superbot.gg is free and runs on your own computer, and a model with no refusal steering does better on the judgement calls this kind of build is about.
